# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within FlinkGuard:
1. Please **do not** open a public issue on GitHub.
2. Report the vulnerability privately to the repository maintainer.
3. Include detailed steps to reproduce, affected endpoints, and potential mitigation strategies.
